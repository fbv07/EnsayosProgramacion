### TIPS PARA LA CREACIÓN DE PÁGINAS WEB

- Para los títulos:
<h1> es para título más grande ahí sucesivamente va hasta <h6>

- Para la parte de arriba de la página, como el logo y demás:
<header> 

- Menú para moverse por el sitio (Inicio, Nosotros, contacto...), va dentro del <header> y contiene listas <ul><li>
<nav>

- Para párrafos:
<p> 

- Para imágenes
<img src="..." > en donde van los punticos es el nombre del archivo, nombre que guardó la imágen

- Para el contenido principal, muestra de productos:
<main>

- Bloque temático como por ejemplo, sobre nosotros, productos, etc:
<section>

- Patio trasero, información, redes sociales, parte final:
<footer>

- Para enlaces:
<a href="...">texto</a> en donde van los punticos va el link

- Para cajas o contenedores genéricos:
<div>

- Para botón:
<button>

- Para listas
<ul> - para inicios de listas y para lista de sección por sección <li>

### SIEMPRE HAY QUE SEGUIR EL SIGUIENTE ORDEN

header - main con section dentro - footer

### SIEMPRE PARA INICIAR UN CÓDIGO EN HTML

<!DOCTYPE html>        - SIEMPRE va primero, le dice al navegador "esto es HTML5"
<html lang="es">       - Abre el documento
<head>                 - Abre head encabezado      
  <meta charset="UTF-8">     - Para que tildes y ñ se vean bien
  <meta name="viewport" content="width=device-width, initial-scale=1.0">  - para que se vea bien en celular
  <title>Nombre de tu página</title>   - lo que aparece en la pestaña del navegador
  <link rel="stylesheet" href="estilos.css">  - Si tu CSS está en archivo aparte
</head>                - Cierra head
<body>                 - Abre body

  - AQUÍ va TODO el contenido visible: header, main, footer -->

</body>                - Cierra body
</html>                - SIEMPRE va al final: cierra el documento
